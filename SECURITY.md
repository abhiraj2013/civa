CIVA Security Policy

About

CIVA is a public civic participation platform designed to help people share public problems, support posts, participate in communities, and publish civic news.

Security and responsible use are important to us.

Reporting a Security Issue

If you discover a security vulnerability in CIVA, please report it responsibly instead of publicly sharing the vulnerability.

When reporting an issue, provide:

- A clear description of the problem
- The affected feature or page
- Steps to reproduce the issue, if possible
- The potential impact
- Any useful screenshots or technical information

Please do not include passwords, private account information, or other sensitive personal data in a report.

Responsible Disclosure

Please allow the CIVA team reasonable time to understand and address a reported security issue before publicly disclosing technical details.

User Safety

Users should not:

- Attempt to access another user's account
- Modify or delete data belonging to other users
- Abuse reporting or community features
- Upload malicious files
- Attempt to disrupt or overload the service
- Use CIVA for illegal or harmful activities

Data Protection

CIVA should collect and process only the information necessary for its features.

Sensitive information should not be unnecessarily exposed through public posts, comments, communities, or news.

Updates

This security policy may be updated as CIVA develops and its security requirements change.
